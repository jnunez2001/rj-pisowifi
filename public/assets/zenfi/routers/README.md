# ZenFi Routers SVG Pack

A polished SVG asset pack based on the approved Routers module visual direction.

Folders:
- icons/: UI icons used by the Routers module
- devices/: router, gateway, AP, switch, server, and client illustrations

Recommended frontend location:
`/public/assets/zenfi/routers/`

Important:
- Use the icons consistently across the Routers module.
- Do not mix icon libraries for the same UI.
- Device illustrations are ZenFi-style generic illustrations. They are not official manufacturer product photography.
- If official hardware imagery is added later, keep the same component dimensions and visual hierarchy.

Primary UI icon family can still be Lucide for dynamic/product UI icons; these SVGs are provided as the approved visual asset set for the Routers mockup and network diagrams.
