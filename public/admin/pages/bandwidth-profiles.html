Where these are used

Vouchers and promo codes can reference a profile by name instead of setting their own download/upload numbers directly. Deleting a profile does not break existing vouchers already using it. They fall back to their own saved numbers, or the global bandwidth cap, the same way a voucher with no profile always has.
