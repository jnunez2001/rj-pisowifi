Firmware Flasher
Flash a vendo's firmware directly over USB, right from this browser — no separate flashing tool needed

This browser can't do USB flashing

This feature needs the Web Serial API, which only Chrome and Microsoft Edge support (version 89+). Open this page in one of those browsers to flash over USB, or use Arduino IDE / esptool.py instead.

1. Choose Firmware File
2. Connect the Device
Plug the ESP8266/ESP32 in via USB directly (not through a hub), then click Connect — your browser will ask you to pick the serial device.
